專注小森林 Focus Forest

種下一顆種子，專心到它長大；中途離開，它就會枯掉。

🔗 網站連結：https://tsczta.github.io/focus-forest/

規格書
1. 動機與目標使用者

大學生讀書、寫作業時容易分心。這個網頁把「專心一段時間」變成「種一棵樹」：完成就長出樹，中途放棄樹就枯死，用視覺與聲音回饋提高專注動力。

2. 核心使用流程
選擇專注時間（15／25／45 分鐘，或自訂 1–180 分鐘），可填寫任務名稱。
按「開始專注」，畫面上的植物隨進度成長（🌱 → 🌿 → 🌳）。
倒數結束：長出一棵樹，種進右側森林，並播放完成音效。
中途放棄：確認後樹枯死（🥀），記錄為失敗。
3. 功能規格
功能	說明
計時器	倒數顯示 mm:ss，支援開始、暫停、繼續、放棄；計時中鎖定設定，分頁標題同步顯示剩餘時間
成長動畫	依進度切換植物圖示並逐漸放大
樹種系統	依專注分鐘數決定樹種：<15 分 🌿 幼苗、15–24 分 🌳 橡樹、25–44 分 🌲 松樹、45–89 分 🌸 櫻花樹、90 分以上 🍎 果樹；開始前預覽將長出的樹種
我的森林	每次專注（成功或失敗）新增一格，滑鼠停留可看樹種、任務、分鐘、日期
統計	成長的樹、專注總分鐘、枯掉的樹，並列出最近 6 筆紀錄
每日目標	可設定每日目標分鐘數（預設 120）；進度條只統計「今天」成功的專注；當天首次達標時顯示慶祝訊息
音效	以 Web Audio API 合成：完成為上行鈴聲，放棄為下行低音；可開關與試聽
深色模式	淺色／深色切換，首次依系統設定，之後記住使用者選擇
資料保存	以 localStorage 儲存紀錄、目標、音效與主題設定；可「清空森林」重置
防呆	放棄前確認視窗；計時中關閉頁面會提醒；分鐘數限制 1–180，目標限制 10–720
4. 介面設計

左側為計時區（天空與土壤場景、大字倒數、設定與按鈕），右側為每日目標、統計與森林。手機寬度下改為上下排列。淺色為草綠、天空藍、土壤棕；深色為夜空藍與深森林綠，並以太陽黃（深色時為月亮色）作強調。

5. 技術

HTML + CSS + 原生 JavaScript，單一 index.html，無外部套件、無外部音檔或圖片。

6. AI 協作與修改紀錄
第 1 版：由 AI 協助發想主題並產出基本版本（計時、成長動畫、森林、統計、localStorage）。
第 2 版：新增完成與放棄音效，提供開關與試聽；因瀏覽器自動播放限制，於按下「開始專注」時初始化音訊。
第 3 版：新增每日專注目標與進度條；紀錄加入日期欄位，只統計當天成功的專注；首次達標有慶祝訊息。
第 4 版：樹種由隨機改為依專注分鐘數決定，並加入開始前預覽與樹種說明。
第 5 版：新增深色模式；所有顏色抽成 CSS 變數；在 <head> 先套用主題以避免畫面閃爍。
7. 已知限制

計時使用 setInterval，瀏覽器在背景分頁降低執行頻率時，倒數可能略有誤差；資料只存在該瀏覽器，換裝置或清除瀏覽資料後會消失。
